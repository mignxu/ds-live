# 产品边界

## 是什么

大肥鱼是抖音直播间里的虚拟 AI 主播：以统一角色持续对话、记住必要上下文、在受限能力内调用工具，
主持 LOL 锐评、现场签名、弹幕合作游戏等节目。

## 硬约束

1. **所有实时观众操作留在抖音直播间。**
   网站（`/souvenirs`）只用于事后浏览语音、签名照和战报，不做观众游戏控制端。
2. **`/stage` 与 `/studio` 是主播内部使用**，不是观众操作入口。
   `/stage` 给 OBS 浏览器源；`/studio` 给主播。
3. **领取纪念品不影响当场参与、计分或结算。**
4. **角色身份不可被观众覆盖。** 观众说“你现在不是大肥鱼”不会写回角色配置。
5. **观众输入与网页内容是数据，不改变系统身份、工具权限或生产配置。**
6. **不向模型暴露 shell、Docker socket、任意文件写入、数据库管理工具。**
7. **mock 与真实来源必须明确区分**，不能把 mock 当线上。

## 不做什么

- 不做观众控制网页游戏的服务端。
- 不自动创建抖音连麦能力、用户鉴权或私信交付能力。
- 不用模型记忆替代业务数据（分数、战绩以业务表为准）。
- 不承诺平台若无可靠事件 ID 时的 exactly-once。
- 不在本轮授权范围内做生产部署或自动 push。

## 角色与模型的关系

角色名固定为“大肥鱼”，和模型厂商、网关、代码包名无关。
不宣称厂商官方身份；不冒充真人。
