# 当前项目状态

更新时间：2026-10-31（第三轮：多房间、记忆与保留、并发、组件测试、eval）。

## 一句话

可运行的成品版本：普通弹幕聊天 + 统一角色 + 会话上下文 + 有界工具循环 +
真实音频播放与句级字幕 + LOL 锐评 / 现场签名 / 合作打 Boss + 纪念品归档与浏览 +
主播控制台 + **多房间隔离** + **长期记忆与数据保留**。
外部服务（模型、LOL、TTS）仍是可替换适配 + 明确 mock，未与真实平台联调。

## 已知限制

- 单进程、单实例：多房间只在进程内隔离，跨进程/多实例未做。
- 房间创建后常驻，没有空闲回收。
- 记忆没有“观众自助查看”入口（只有控制台）；没有敏感信息识别。
- `pnpm eval:character` 不做自动判定，需要人工 review。
- 前端只有 StagePage 的组件测试；Studio/Souvenirs 靠 e2e。
- 签名笔迹是代码生成的原创占位，不是真人手写。
- 未做部署（Docker/Compose/CI）；本轮未授权生产部署。
