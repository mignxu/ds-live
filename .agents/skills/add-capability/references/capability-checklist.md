# 新增能力检查清单

## 契约

- [ ] 工具名已加入 `ToolNameSchema`（前后端共用，不能各写一份）
- [ ] 参数 JSON Schema 与宿主 zod schema 一致
- [ ] 结果字段符合 `ToolResultSchema`，失败时 `data === null`
- [ ] `errorCode` 使用契约枚举，没有自造字符串

## 权限

- [ ] 工具在 `allowedTools` 白名单内（默认最小集）
- [ ] 需要新权限时，权限属于**工具能力**，不是“管理员全开”
- [ ] 不暴露 shell / Docker / 任意路径写入 / 数据库管理
- [ ] 网络请求经过统一 egress 校验（域名、DNS、重定向每一跳、响应体大小、拒绝内网与元数据地址）

## 预算与取消

- [ ] 执行遵守 `AbortSignal`
- [ ] 有超时上限，超时返回 `timeout` 且 `retryable` 语义正确
- [ ] 不自动无限重试
- [ ] 超出本轮预算的请求被拒绝并回报，不是静默丢弃
- [ ] 底层不可中断的调用：结果过期后不发布到新轮次

## mock 与真实来源

- [ ] mock 实现与真实适配器实现同一个接口
- [ ] `isMock` 一路传到舞台、纪念品、日志
- [ ] 真实适配器缺凭证时显式失败或显式降级，不静默假装可用
- [ ] `docs/references.md` 记录了待核实的契约细节

## 节目（如果新增的是节目）

- [ ] 实现 `match/handle/snapshot/cancel` 四个方法
- [ ] 不自行创建播放线程，不自行调用模型供应商
- [ ] 分数与结算只由程序规则决定，模型不能直接改
- [ ] 迟到输入不进入已结束回合
- [ ] 取消后状态干净，不残留“进行中”

## 数据

- [ ] 新表通过编号迁移添加，不手改生产表
- [ ] 记录带状态、来源、时间、traceId
- [ ] 保留期限可配置，有清理路径

## 文档

- [ ] `docs/features/` 写了行为与验收
- [ ] `docs/decisions/` 记录了不显然的取舍
- [ ] `docs/tasks.md` 移除了完成项
